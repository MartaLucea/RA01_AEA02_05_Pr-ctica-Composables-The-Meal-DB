# Hobbits de LOTR

Aplicació web feta amb Vue 3, Vite i Vue Router que consumeix [The One API](https://the-one-api.dev/) mitjançant un composable (`useFetch`). Permet cercar hobbits per nom i consultar-ne el detall (dades i cites).

### Instal·lació
npm install

### Execució (Desenvolupament)
npm run dev

### Producció
npm run build
